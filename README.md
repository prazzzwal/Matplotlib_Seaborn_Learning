# Matplotlib & Seaborn Learning Notebooks

This repository contains **Jupyter notebooks** for learning data visualization in Python 
using **Matplotlib** and **Seaborn**. The notebooks are organized from **basic plots** to 
**advanced visualization techniques**, and include **mini-projects** to practice your skills.

## 📂 Folder Structure

- **1_Basics_Matplotlib**: Line plots, scatter plots, bar charts, histograms.
- **2_Intermediate_Matplotlib**: Subplots, multiple lines, annotations, custom ticks.
- **3_Basics_Seaborn**: Scatterplots, lineplots, barplots, boxplots, histograms with KDE.
- **4_Advanced_Seaborn**: Pair plots, heatmaps, regression plots, categorical plots, facet grids.
- **5_Styling_Aesthetics**: Themes, color palettes, combining Matplotlib and Seaborn.
- **6_Mini_Projects**: Real-world projects like stock analysis, weather visualization, dashboards.
